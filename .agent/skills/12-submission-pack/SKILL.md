# 12 Submission Package

## Purpose

Produce an uploadable package. A checklist, readiness score, or blocker report is
not the package.

## Workflow

1. Verify the current official venue file requirements.
2. Build or update the actual manuscript PDF/source, bibliography, figures,
   tables, supplement, cover letter, highlights, declarations, and author data
   that are required.
3. Open the produced files and check filenames, completeness, and obvious content
   inconsistencies.
4. Compile once when TeX or source packaging changed.
5. Report only missing information that prevents submission.

For an explicitly requested readiness check, inspect the existing package and fix
concrete defects when authorized.

## Output Contract

Produce the required uploadable files and a concise list of any author-supplied
information still missing.

## Boundaries

- Do not submit, publish, or push without explicit authorization.
- Do not spend the task building a readiness dashboard or multi-layer review
  packet.
- Do not polish layout beyond venue requirements and clear readability.
- Do not calculate file hashes or create receipts.
- Do not invent author, funding, ethics, or conflict information.
