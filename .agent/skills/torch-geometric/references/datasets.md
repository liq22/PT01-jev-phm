# Common Datasets by Task

Canonical reviewer-accepted benchmarks per task level. Use this to pick a
dataset a venue will recognize for a node-, graph-, link-, molecular-, or
point-cloud claim. Always log the chosen dataset and split in
`paper/experiments/run_ledger.md` and `paper/experiments/reproducibility.md`.

- **Node classification**: Planetoid (Cora / Citeseer / Pubmed), OGB
  (ogbn-arxiv, ogbn-products, ogbn-mag)
- **Graph classification**: TUDataset (MUTAG, ENZYMES, PROTEINS, IMDB-BINARY),
  OGB (ogbg-molhiv)
- **Link prediction**: OGB (ogbl-collab, ogbl-citation2)
- **Molecular**: QM7, QM9, MoleculeNet
- **Point cloud / mesh**: ShapeNet, ModelNet10 / ModelNet40, FAUST
