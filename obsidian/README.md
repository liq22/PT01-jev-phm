# 可选 Obsidian 草稿区

`obsidian/` 只用于临时笔记，不是 PaperTrace 的必需目录，也不保存当前研究状态。

- 当前研究状态：`paper/paper.yaml`
- 当前正文：`paper.yaml.active_source`
- 研究历史：`paper/logs/research_log.md`
- 论文变更历史：`paper/logs/paper_log.md`

可把尚未判断的碎片写入 `inbox.md`。一旦内容改变研究决策或论文主张，应迁移到上述正式位置并从 inbox 删除。

仓库不再捆绑 Obsidian 插件。插件、个人工作区、缓存和界面设置应由用户在本机安装和维护，不进入 PaperTrace 模板。
