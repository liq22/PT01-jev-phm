# Jev-PHM figures

The original pilot method and empirical SVG/PDF figures are generated by
`src/S03_Scripts/plot_jev_results.py`. The new Jev-PHM framework diagram is a
hand-authored vector SVG (not a plot-script output). All SVG text remains editable;
`paper/draft/main.md` is the source of the manuscript captions.

- `jev_phm_framework.svg`: the **proposed Jev-PHM semantic architecture** in
  manuscript Section 4. The upper lane depicts the non-generative inference
  contract (signal adapter, compatible backbone, description encoder, shared
  candidate scores, categorical probabilities and diagnosis/deferral); the
  lower lane depicts verified source-side annotation maps and event-likelihood
  training. This diagram is **not** the implemented six-feature PU method or
  the 46-feature simulation. The optional conditional KL is not drawn as an
  essential framework block: the simulated selected penalty and extra update
  were both zero. Object groups and live text in the SVG are directly editable.
- `jev_method.svg`: the implemented six-statistic observation, independently
  evaluated fault-presence and conditional fault-type branches, code-owned leaf
  probability composition, calibration and cost-based diagnosis/deferral.
  Branch targets come from diagnosis labels, not independently observed physical
  concepts. This is a method diagram, not empirical mechanism evidence.
- `jev_primary_results.svg`: paired primary-test bearing NLL differences with
  conditional 95% intervals, followed by pooled-calibration risk–coverage curves
  for all six arms. Negative differences favor the first named arm. Intervals use
  2,000 paired resamples of eight physical bearings, seed 20260922, and condition
  on the fitted models and frozen split. Curves use equal-bearing window weights
  and stable saved observation-order ties; overlapping windows are not resampled
  independently.
- `jev_rotation_contrasts.svg`: paired NLL differences in the six predeclared
  refitted validation cases, with each train/tune-selected window length shown.
  The three comparisons use the question-conditioned factorization against flat,
  shared-representation factorized and two-direct-question Qwen controls. Lines
  connect the displayed cases for reading; rotations have overlapping fitting
  populations and are not independent seeds or an uncertainty interval.

The empirical figures read only saved predictions and metadata from
`src/outputs/jev-phm/run-20261013-pu-001`. All nine evaluations' metrics, risk–
coverage arrays and paired contrasts were recomputed from the saved logits and
checked before drawing. They preserve unfavorable results and do not rerun
inference. Numerical data and configurations are retained in the companion
tables directory; larger arrays remain in the ignored run directory.

Rebuild all figures and tables from the repository root:

```bash
CUDA_VISIBLE_DEVICES='' OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python src/S03_Scripts/plot_jev_results.py \
  --run-root src/outputs/jev-phm/run-20261013-pu-001
```

The method diagram alone can be generated with the same command plus
`--method-only`, without any empirical artifact or result claim.

To preview the framework SVG without running the model or old plotting script:

```bash
inkscape paper/assets/figures/jev_phm_framework.svg --export-type=pdf \\
  --export-filename=/tmp/jev_phm_framework.pdf
inkscape paper/assets/figures/jev_phm_framework.svg --export-type=png \\
  --export-filename=/tmp/jev_phm_framework.png --export-width=1950
```

The framework asset has no embedded raster image. PDF/PNG are derived previews;
they are not additional manuscript or result sources.
