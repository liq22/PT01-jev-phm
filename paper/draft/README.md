# Markdown 正文

`paper/draft/main.md` 是 `idea`、`outline` 和 `markdown_draft` 阶段的 active source。

只写当前任务需要且有证据支持的内容。章节内容形成后再创建对应文件并从 `main.md` 引用；不要预建空 Abstract、Introduction、Method、Experiment、Result 或 Conclusion。

写作前确认：

```text
当前研究问题
承担本段结论的事实或结果
允许的 claim 强度
必要的适用范围和不确定性
```

科学内容不完整时，先处理文献、理论、代码、实验或统计问题。内部 Skill 名称、路径、ID、状态、gate、ledger、manifest 和 backend 细节不得进入论文正文。

Markdown 正式化为 TeX 后，以 `paper.yaml.active_source` 指定的 TeX 文件为唯一正式源。
