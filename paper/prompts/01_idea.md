# Idea：从现象到可检验假设

按 [使用说明](README.md) 选择一个任务。初步 idea 之后先完成 [文献比较](02_literature.md)，再正式化假设；已有正式方向从当前未决机制进入。

## 初步 idea

主 Skill：[scientific-brainstorming](../../.agent/skills/scientific-brainstorming/SKILL.md)。适合 GPT Pro 深度讨论。

```text
基于本次给出的研究对象、真实观察、现有文献和资源限制，凝练可研究的问题。
有项目访问权限时先读适用规则与既有研究状态；没有权限的材料明确为缺失。
本轮产物是候选研究判断，沿用已知事实与作者决定，不重做有效工作。

读取 K-Dense 的 scientific-brainstorming 作为本轮外部支持：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/scientific-brainstorming/SKILL.md
用其问题重述、机制联想和竞争解释方法产生候选；数量、选择与产物位置沿用
本项目约定，不增加候选评分或另一套登记系统。

1. 分清已经观察到的现象、尚待解释的矛盾、假设与愿望。
   没有真实失败或矛盾时保持 unknown，指出最有信息量的观察或检索。
2. 最多保留 3 个机制不同的候选，零个或一个也合法。
   每个候选说明：改变的科学对象、已有原理、最小变化、候选机制、
   区别性预测、最强替代解释、最近邻已知差异或待检索问题、最小反证。
3. 优先考虑更简单的解释和方法；组件组合、术语变化、工程封装不自动构成创新。
   不为凑数量、取名称或匹配目标期刊制造候选。
4. 比较哪个未知最值得先解决，以及一个正、负或边界结果将如何改变选择。

输出简明候选比较与首项决定性工作；有写权限时更新既有候选/创新卡。
暂定推荐与正式作者选择分开。若提供了参考图，提取其有效科学操作；
未提供图或原文时，不声称已按图分析。
```

## 正式 idea 与竞争假设

主 Skill：[hypothesis-generation](../../.agent/skills/hypothesis-generation/SKILL.md)。输入是一项候选与已核验的最近邻比较。

```text
基于本次选定供讨论的候选、原始相关文献、现有实现和研究观察，
把方法设想凝练成可证伪的正式 idea。先核实实际项目规则和作者既有决定；
本轮不重新发散出一批候选，也不把模型推荐写成作者批准。

读取 K-Dense 的 hypothesis-generation，实际用于竞争解释与区别性预测：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/hypothesis-generation/SKILL.md
围绕本次一项候选采用其假设和检验设计能力，输出下述可审阅 idea。

形成一页正式 idea，逐项写清：
- 一个核心科学问题及对象、观测、任务和适用条件；
- 与 3–5 项最近邻在假设、对象、操作或结论上的具体增量；
- 一个最小机制、最强竞争解释，以及可能模拟收益的主要混杂因素；
- 两种解释分别预测的可观测结果；
- 最少必要变量、输入输出和算法操作；
- 1–3 项不重复的候选贡献，每项对应决定性验证；
- 支持、否定、边界成立和信息不足时如何修改判断；
- 首项验证、实际资源需求及停止条件。

保留假设产生时间：实验前提出、探索结果启发、独立确认或仍为事后解释。
必要数学表达用可复制的 $$ LaTeX $$，先定义符号再使用，不添加装饰性公式。
不能用方法名字代替机制，不能用预期精度代替科学预测。

返回可直接与作者讨论的正式 idea 和唯一最关键未决问题。
后续由 motivation 任务将同一机制画清；材料齐备后再作选题决定。
```

## Motivation 草图与选题确认

主 Skill：[15-figure-table-design](../../.agent/skills/15-figure-table-design/SKILL.md)。绘图工具作为该主 Skill 的支持能力。

```text
依据已经形成的正式 idea、最近邻比较和正确的变量定义，制作 motivation 图。
先读实际论文/图源规范；将本次提供的参考图作为视觉依据，不能补造其内容。

读取 nature-figure 的完整入口及概念草图相关资源，指导本次科学构图：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-figure/SKILL.md
沿用当前已授权图像工具；明确本次采用的构图与语义检查，不扩展为定量图
或全套上游绘图流程。只有实际生成或检查的部分才报告完成。

图中明确表达：真实现象或未解决条件、最强已有机制依赖的前提、
本文改变的科学对象或约束，以及竞争解释产生不同预测的条件。
保持信息权限一致，标明尚未验证的推断；不画虚构准确率或已发生的优势。

按本次要求先用可用的 GPT Image 生成构图草案，并依据正确科学内容检查：
箭头意义、变量、标签、比较条件和图注。图像生成不可用时，交付精确构图描述
与可复制生成 prompt，明确草图尚未生成，不声称已调用 GPT Pro 或 Image。
只在作者需要最终矢量资产时重构独立形状、文字与连线，沿用唯一图源。

交付草图/实际资产、英文 caption 和必要的语义修正说明。
连同正式 idea 与最近邻差异，形成可审阅的选题材料。
没有该方向的作者决定时请求确认；相同方向已获批准时继承并报告下一步。
作者未选择前，不把暂定候选写为已经批准的论文方向。
```
