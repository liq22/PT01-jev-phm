# 真实实验与预期图表

先完成协议，再把完整图表模板、运行矩阵和预算交给作者审阅。对应 [使用说明](README.md) 的实验决定；已有有效授权不重复确认。

## 至少两个独立真实数据集的实验协议

主 Skill：[experimental-design](../../.agent/skills/experimental-design/SKILL.md)。

```text
基于当前方法、已完成的最小验证、最近邻原始 PDF 和真实可用数据，
设计能够检验 1 个核心问题和 1–3 项主张的最小充分实验。
先读取既有规则、协议、作者决定与资源；本轮设计，不启动完整实验。

读取外部 statistical-analysis，采用其估计目标、独立单位和配对/聚类分析设计：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/statistical-analysis/SKILL.md
用于明确当前实验需要的精度与区间；本项目独立数据源和评价协议仍是依据。
本轮不运行分析或编造数值，不机械安装上游整套环境或套用固定报告格式。

本次经验研究要求至少两个独立真实数据集。核验来源、设备、记录、
故障/标签含义、传感器、工况和可获取范围。
同一记录的窗口、不同采样率副本或两个目录不能计作两项独立来源。
先按设备/记录/运行批次等实际独立单位划分，再生成窗口；
说明未见设备或工况如何形成，以及训练、验证、测试的信息权限。
若当前项目为综述或纯理论，依据其科学责任设计验证，不强填数据集数量。

逐篇对标最相关的原始实验：论文、PDF 路径、页码、Table/Figure 编号、
Learning Setting、划分、指标、重复方式、强基线与不可直接比较的条件。
选择最近邻竞争方法与简单替代，优先官方实现/可审查复现，核对 checkpoint、
训练目标和模型选择。公平性是合理且可解释的机会，不是机械相同超参数。

每项实验写明 Claim → Hypothesis → Baseline → Protocol → Metric
→ Expected pattern → Falsification criterion。
区分性能、机制、泛化、稳健性与效率主张；按主张选择必要实验，
避免无意义的模型×数据集×种子全组合。
设置额外知识、预训练、工具或计算预算的匹配对照，排除最强替代解释。

明确真实统计单位、主要指标、效应与不确定性、必要重复数、运行优先级、
总预算、单次上限、有限技术重试、停止规则及最终测试何时可读。
算法/超参选择只使用开发信号；读取最终测试后再修改模型须承认其开发使用。

输出既有协议和完整运行矩阵的必要更新，以及仍缺的真实输入。
结果交给图表模板任务，供作者连同预算一次审阅。
```

## 最终结果图表模板与实验确认

主 Skill：[15-figure-table-design](../../.agent/skills/15-figure-table-design/SKILL.md)。

```text
依据当前论文、已核验原始 PDF、真实数据协议与候选贡献，
设计可直接指导执行的最终论文图表模板。本轮只设计模板，不批量运行实验。
沿用有效图源、论文编号和已有作者决定，不新建一组平行结果稿。

读取 nature-figure，用其面板证据分工、图例与科学表达能力设计模板：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-figure/SKILL.md
仅采用规划相关资源，不启动绘图后端或真实结果生成；未运行值继续使用 TBD。

1. 给出文献实验对标表：PDF、页码、原始图表编号、可借鉴内容与比较限制。
2. 给出 Claim–Experiment 对应关系，明确每项比较为何不可省略。
3. 每张表提供完整 Markdown 行列、英文标题、方法/对照、数据集/设置、
   主要指标、效应和适用的不确定性字段。均值±标准差不是所有设计的统一答案。
4. 每张图给出英文 caption、子图布局、轴和单位、曲线/分组、图例、
   独立单位、不确定性表达、实际数据来源或待生成位置，以及拟支撑结论。
5. 分别说明支持假设、否定假设和信息不足时应出现什么模式，
   以及哪种结果可由更简单解释说明。

文献真实结果、本文已有结果和预期趋势严格区分；未运行值一律 TBD。
不预设排名、显著性或 Ours 全面最优，也不把“理想趋势”当作数据生成目标。
若仅需示意排版，明确标记 Illustrative，不能混入结果正文。
只保留提供独立科学信息的图表，避免同一结论重复画图。

交付可审阅的完整图表模板、协议、运行配置矩阵、执行优先级与预算。
若该实验范围尚未获作者确认，在材料齐备后请求确认再启动完整运行；
同一范围与预算已有有效确认时继承，直接交接已授权的实现/执行任务。
```
