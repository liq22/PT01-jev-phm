# 本地执行与创新判断

按 [使用说明](README.md) 继承作者决定。实现、运行、有效测量与科学支持分别报告。

## 通用实现、配置与完整 Shell

主 Skill：[code-change](../../.agent/skills/code-change/SKILL.md)。

```text
依据当前方法、已确认协议和图表模板，完成本轮必要实现，并交付完整本地运行 sh。
先读实际 README/AGENTS、源码、配置与已有测试，核验当前分支和未提交改动。
实际 CLI 的帮助、源码与配置语义是依据，不猜包名、字段或运行命令。

Python 实现通用算法、训练/推理、评价和必要统计；YAML/config 表达实验差异；
Shell 列出并调用本轮完整配置。Python 不写 E1/E2/E3 或论文图表编号的分支，
也不为每项实验复制独立程序。不同科学算法保留有清楚职责的必要模块。

先绑定现有运行入口、配置参数名、环境、工作目录与输出语义。
复用已有 PHMFactory/其他框架，不新增第二运行器。
方法、数据、seed、设备、checkpoint 和资源限制使用真实支持的配置方式；
后续同类实验主要调整配置内容及 Shell 中的 config/YAML 路径。

交付 run_all.sh 或项目已有同职脚本的完整更新：
- 本轮必须运行的全部真实配置，及其必要顺序/已有依赖；
- 实际环境、数据、元数据、checkpoint、设备和运行位置；
- 真实 CLI、原生恢复语义与输出位置；
- 失败、完成和未运行项的识别方式；
- 已有结果汇总/绘图入口和运行后的检查方式。

缺输入、配置错误、设备不可用应明确失败，不能换 synthetic、默认几何参数、
CPU 或另一个 checkpoint。恢复运行不能覆盖有效产物或隐藏失败。
错误重试只修复同一操作，不悄悄改变科学问题。

完成最小有意义的端到端验证并检查实际输出；局部测试优先，完整套件按仓库
既有 PR 要求执行。纯脚本语法通过不等于实验完成。
返回可直接在真实环境运行的脚本与已验证入口；未绑定真实环境的示例必须
标为未完成，不能将带占位符的命令称作可运行交付。
```

## 执行完整必要实验

主 Skill：[06-experiment-ops](../../.agent/skills/06-experiment-ops/SKILL.md)。

```text
运行当前已经确认的实验与图表矩阵，使用现有完整 Shell、通用入口和实际配置。
先核验方法、数据/标签/划分、指标、干预、强基线、输出和授权预算；
同一范围已有作者确认时直接继承，不再逐项询问。

按已确认优先级完成必要实验，检查每项真实产物而非只看退出码。
记录配置、版本、实际输入、必要复现信息和失败原因，沿用已有实验记录。
干预有无被赋予、接收、使用和产生行为效果按主张需要检查。
有效的非使用或负结果保留，不能改名为失败运行后丢弃。

允许使用当前固定版本、已启用且在白名单内的 ARIS 单项能力，
经现有 adapter 调用；不运行上游 installer、高层 research/review loop，
不额外创建自治控制器或假设 GPT Pro 可被自动调用。
run-experiment 的固定外部入口（Codex 版）是：
https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/3e49e63aae6a653067f9e2101d50457f1f7d6a2f/skills/skills-codex/run-experiment/SKILL.md
实际读取 adapter 为当前环境解析的对应 Skill，采用所需启动、监控和产物检查；
具体 Shell/config、环境与授权范围由本项目决定，不能直接执行上游占位命令。

若本轮授权自动改进，在执行前落实：允许改动范围、开发信号、
单次/总预算、有限技术重试、无新增区分信息的停止标准及最终评价条件。
每轮一个可解释改动，保留所有尝试；数据划分、主指标、信息权限、
强基线规则与最终测试不能随结果调整。
达到预算、获得充分区分结果、必要预测被有效反证或缺少必要输入时停止相应循环。

最终测试只在预定条件下调用。读过其分数再改模型，应说明旧测试参与开发，
采用独立确认条件或收缩结论，不能继续称作完全未见测试。

返回完成/失败/未运行项、实际结果位置、预算使用及直接检查结果。
若只有本地脚本而无运行环境，明确尚未执行和最小缺口；独立准备工作继续完成。
“全部完成”必须对应确认矩阵中的全部必要项，不能只返回一条启动命令。
```

## 统计与机制结果分析

主 Skill：[statistical-analysis](../../.agent/skills/statistical-analysis/SKILL.md)。

```text
基于指定的实际运行产物与已确认协议，分析结果是否区分了预设解释。
先核对独立单位、有效数量、缺失、配对/聚类、实验设置和基线可比性。
不能从文件名或希望得到的结论推断这些信息。

优先读取外部 statistical-analysis，完成与本次设计对应的实际统计分析：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/statistical-analysis/SKILL.md
若本轮已选择且启用了 ARIS analyze-results，则以它作为本次一个支持：
https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/3e49e63aae6a653067f9e2101d50457f1f7d6a2f/skills/skills-codex/analyze-results/SKILL.md
按需择一，沿用项目统计单位与估计目标；不机械采用相对提升、seed 标准差、
显著性阈值或上游示例依赖版本。

使用与研究设计匹配的最简单分析，报告效应大小和适用的不确定性。
窗口数、fold 数和随机种子数不等于独立设备或样本数量。
统计检验、重采样、层级模型、多重比较和敏感性分析仅在问题确有需要时使用；
不在看到显著性后更换方法，不把不显著解释为没有效应。

比较主结果、必要消融、匹配对照和边界条件；保留负结果与失败运行信息。
明确观察到什么、什么解释得到支持、什么解释仍无法排除。
性能差异不自动证明机制、因果关系或一般泛化。

更新既有结果表与需要重算的图表数据，附实际输入和分析入口。
指出仍缺的最小区分信息；只有已执行计算才能提供数值结论。
```

## 创新主张判断

主 Skill：[05-claim-evidence](../../.agent/skills/05-claim-evidence/SKILL.md)。适合由 GPT Pro 阅读原始证明与结果作集中判断。

```text
基于当前主张、最近邻原文、完整证明与实际有效结果，判断本文新增了什么知识。
直接读取支撑材料，不能只依赖另一 Agent 的成功总结。
先区分实现完成、运行完成、测量有效和科学支持，再逐条判断候选贡献。

读取外部 scientific-critical-thinking，实际用于评价证据强度与竞争解释：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/scientific-critical-thinking/SKILL.md
保留本项目主张含义和支持规则，以真实证据决定下面的判断，不以评分替代。

对每条主张给出：类型、原始依据、实际效应/不确定性、最强替代解释、
Supported / Refuted / Inconclusive、适用范围、允许写入论文的具体措辞，
以及停止/最小补充/修改方法的下一项动作。

Supported 只用于相应条件下已经成立的主张；部分条件成立时，
单独写出受限结论，不能把原来的广义主张整体通过。
Refuted 需要有效反证；缺数据、实现错误或区间过宽通常仍为 Inconclusive。
理论保证由证明负责，实际收益由有效实验负责，二者不互相替代。

检查收益能否由简单方法、更多信息、额外预算、数据偏差或选择性报告解释。
保留探索发现的产生时间和独立确认需求；不把后验解释改写为实验前假设。
主假设被否定时停止同类堆实验；得到充分支持时停止无必要调参并进入写作。

更新既有贡献/结果对照与真实研究状态；STATUS 仅作为进展视图引用，
PaperTrace 的 paper.yaml 继续维护当前事实与作者决定。
返回仍可成立的科学增量、不能下的结论和唯一最有信息量的下一步。
```
