# 全文、图表与投稿

按 [使用说明](README.md) 分步执行。已知文献、方法和协议可在研究中持续写入；最终贡献强度、摘要、结果与结论由真实结果决定。

## 全文与意群

主 Skill：[08-markdown-draft](../../.agent/skills/08-markdown-draft/SKILL.md)。

```text
基于当前论文、已核验原文、真实方法和已经支持的主张，完成或优化唯一有效全文。
先读项目规则、Paper Skill Core、当前 active_source 与相邻内容。
沿用有效正文、引用、公式和负结果，按当前缺口逐节推进，不另开平行最终稿。

读取 K-Dense 的 scientific-writing，采用其章节组织与证据驱动写作能力：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/scientific-writing/SKILL.md
直接写入本项目唯一正文，引用和证据沿用现有载体；不引入上游多账本、
逐行哈希或另一 submission_ready 权威，也不把工具自引当成本文科学依据。

用一个核心问题和 1–3 项有依据的贡献贯穿全篇。
Introduction 说明问题、最近邻已有能力、具体缺口、动机与本文可检验增量；
Related Work 比较假设、机制、协议、结果与边界；Method 定义对象、假设、
formulation、算法和必要实现；Results 报告真实效应、波动、对照和负结果；
Discussion 解释机制、替代解释与适用范围；Conclusion 凝练新增认识。

按论证需要使用 Background → Problem → Closest Related Work → Gap
→ Motivation → Challenges → Method → Contributions，不能机械变成八个标题。
每段只推进一个明确目的，保持技术对象稳定；句间关系必须是真实的解释、
比较、条件、因果或递进，不能靠连接词拼接无关句子。
定义先于使用，观察与解释分开，一概念一术语，明确谁在什么条件下改变何量。

保留未完成理论责任、真实不确定性和边界；缺结果的局部保持待完成，
不通过改措辞、换术语或删除负结果制造创新。
输出实际正文更新和影响科学含义的必要改动说明。
```

## 结果图、流程图与拼图定稿

主 Skill：[15-figure-table-design](../../.agent/skills/15-figure-table-design/SKILL.md)。

```text
根据已经核验的实际结果、正确方法和现有图表模板，完成论文图表及英文 caption。
本轮主 Skill 为 15-figure-table-design；选择 nature-figure 作为一个专项支持。
先完整读取其固定版本入口，再读本次采用部分需要的资源：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-figure/SKILL.md
同一版本先读 manifest.yaml 及其 always_load：static/core/contract.md、
static/core/stance.md；上游正文 core/... 为简写，真实路径在 static/core/。
版本于 2026-10-17 核验。本次采用与具体图件有关的科学构图、面板分工、
图例和图件检查指导；项目本地科学约定、实际工具和作者已确认决定优先。

读取项目提供的 Nature/目标期刊绘图规范和既有图源，按实际投稿尺寸设计。
沿用本项目已确认的绘图后端；只读或规划任务无需选择运行后端。
不擅增 API 调用、全局偏好文件或审批步骤。可读规范即可支持分析，
实际脚本和软件操作才需要运行环境；不把链接存在当作已经安装或运行。
外部支持不可读或必要运行能力缺失时完成已授权可行部分，说明具体缺口。

定量曲线、统计图、表格和误差表达必须由真实数据经项目已有绘图工具生成。
核对单位、比较组、独立单位、汇总方法、区间意义、负结果及每个 panel 的来源。
ImageGen 只用于概念草图，不能生成精确实验数值或替代真实样本。

方法/流程图依据真实计算关系重建为可分别编辑的文字、形状和连接。
拼图复用已经核验的 panels，每个子图回答不同科学问题；避免装饰性重复。
Illustrator 可优化排版与非数据图形，不能手拖数据点、曲线或误差条。

按实际需要使用 Visio 或 Illustrator；只有打开、编辑、保存并重开后，
才能报告原生软件编辑验收通过。SVG 内嵌整张 PNG 或单一路径不算可编辑重构。
保留一个维护源，按期刊需要导出，不为完整性同时创建所有格式。

打开最终资产，核验数据、拓扑、标签、缩放可读性、图例和 caption。
若使用上游 audit 脚本，先核验脚本、依赖、输入和真实输出；
只读取规范不能声称 audit passed，不要求机械生成全部上游 QA 记录。
说明本次实际采用和完成的检查，不声称运行了整套 Nature 图件流程。
交付真实图源/导出物及尚未完成的软件或科学核验，不能把规格书当作已生成图。
```

## De-AI 与稳定表达

主 Skill：[10-language-polish](../../.agent/skills/10-language-polish/SKILL.md)；需要去除防御性叙述时读取其 `anti-defensive-writing` 支持。

```text
对指定稳定稿件做 De-AI 和语言优化，先读原文、相邻段落、术语与科学边界。
改善意群、句间逻辑与专业表达，删除空洞形容、套话、虚假转折、重复总结和
不改变解释的防御性叙述；保持一个概念对应一个术语。

前后核对科学含义：对象、因果方向、比较组、假设、机制、公式、数值、单位、
样本量、引用、负结果、不确定性和结论强度必须保留。
发现真正科学歧义时指出所需判断，不用润色把它掩盖。
工程封装不能改名为机制创新，必要技术术语不能按禁词表删除。

直接更新授权范围内的稳定文本；不使用 AI 检测分数、词频配额、句长阈值
或 Python 文风扫描作为验收。真实工具使用说明与期刊所需声明保持准确。
```

## 引文准确性

主 Skill：[11-reference-audit](../../.agent/skills/11-reference-audit/SKILL.md)。

```text
在当前终稿范围核查引文，读取唯一正文、BibTeX、原始 PDF 与权威题录。
读取外部 citation-management，执行本轮需要的题录检索与 BibTeX 修复：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/citation-management/SKILL.md
使用实际可用渠道，保留现有引用键和合法来源类型；论断是否被支持仍回到原文。
逐项检查：论文存在与版本身份；题名、作者、年份及出版状态；
引用是否支持紧邻论断；比较矩阵、图注及最近邻局限是否与原文条件一致；
正文引用键与参考文献表是否一致。

关键方法、结果或缺失能力判断必须回到原文，不用摘要或二手综述替代。
来源无法支持时，寻找正确来源、修正具体陈述或移除无依据判断，
不能保留强论断再随意换 citation。合法缺少 DOI/卷期的来源不判作虚假。

有修改授权时直接修正正文与既有题录，只复核改变部分及关键支撑。
列出仍影响中心结论的来源缺口和准确位置，不建立第二引用台账或审计包。
```

## 一次集中终稿复审

主 Skill：[peer-review](../../.agent/skills/peer-review/SKILL.md)。

```text
对现有终稿做一次集中、只读的科学复审。直接读取稿件、最近邻原文、证明、
实验协议与实际结果；继承已知问题，避免把同一问题换不同措辞重复计数。
本轮主 Skill 为 peer-review；选择 nature-reviewer 作为一个专项支持。
完整读取固定版本入口，再按当前稿件读取必要原始标准和领域参考：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-reviewer/SKILL.md
先读同一版本的 references/source-basis.md，区分 Nature 本地归档标准和
仓库实现规则；目标期刊当前政策仍查官方。可读取的规范即可支持本轮审阅。
版本于 2026-10-17 核验。本次仅采用有依据的审查维度、陈述/证据指向、
问题严重性和解决检验，服务于一次 focused peer-review。
遵守 Paper Skill Core 与本项目科学约定，不执行上游默认三互盲报告、综合和
额外 forensic 审计包，不声称整套 nature-reviewer 已运行。

优先核查：实质最近邻增量、理论条件/反例、机制与实现、强基线公平性、
独立单位与统计、泛化边界、图表/引用支撑、跨章节矛盾及段落逻辑。
按论文类型选择维度；综述额外核查覆盖、taxonomy、跨研究综合和新认识，
不把综述专属模板机械用于普通方法论文。

每项关键发现写明位置、原文/产物依据、技术问题、最小修订与验收条件。
区分 Major/Minor 与是否影响中心结论；目标期刊要求决定适配边界，
不能将 Nature 的跨学科读者标准机械作为专业期刊的否决条件。
数值异常须核对真实计算或来源，不凭外观认定伪造；缺材料保持不可评估。
给出仍成立的贡献、最强反例和修订顺序；没有问题数量或模型评分配额。
本轮不一边改稿一边声称独立审阅，也不启动固定轮数的对抗循环。
只有作者另行明确要求多份独立报告，才使用真实隔离上下文，报告完成后再综合；
同上下文多角色不是互盲，独立会话也不自动等于不同模型家族。
上游不可读时完成已授权的可行审查并标明缺口，不假称使用了未读取的支持。
后续按已经授予的修订权限处理实际问题，只有相关改动才复查受影响内容。
```

## 真实审稿意见回复

主 Skill：[13-reviewer-response](../../.agent/skills/13-reviewer-response/SKILL.md)。输入是实际编辑信、审稿评论或已有回复；这是独立返修任务，不是模拟审稿后的自动步骤。

```text
根据本次提供的真实编辑信、reviewer comments 和当前稿件，处理已授权的返修。
本轮主 Skill 为 13-reviewer-response；选择 nature-response 作为一个专项支持。
完整读取其固定版本入口和本次回复任务所需资源：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-response/SKILL.md
同一版本先读 manifest.yaml 及其 always_load：static/core/stance.md、
static/core/workflow.md；上游正文 core/... 为简写，真实路径在 static/core/。
可读规范即可支持回复修订；实际运行脚本或编译时才核实对应运行能力。
版本于 2026-10-17 核验。本次采用逐点回应、真实工作状态、精确稿件位置、
专业回应方式以及稿件—回复一致性检查，保留本项目既有正文、回复和科学约定。

先从真实材料识别编辑决定、要求、编号和审稿可见性，不从意见语气/数量猜测。
缺少编辑决定只影响依赖它的包级策略，不阻止有依据的局部回复修订。
没有真实意见时说明缺输入，不把模拟 reviewer 报告冒充收到的审稿意见。

逐项判断需要科学修改、补证、澄清、收缩主张还是有依据的不同意见。
先完成已经授权的必要实验、分析或正文修改，再写已完成的回复措辞。
每条回应说明答案、实际改动、依据与可核查稿件位置；尚未完成的工作明确标出。
缺少实验、文献或作者事实不能编造，审稿人未看清的关键内容按需要改善表达。

复用当前回复正文和 LaTeX 模板；只在实际编辑要求需要时生成分 reviewer 文件、
cover letter 或标注稿。小段修改不扩展成全套返修包。
不新增 master tracker、第二 readiness、平行回复文本或强制全部标红。
如需进展更新，复用现有 STATUS 视图；论文既定状态权威保持不变。

核对回复的完成声明、引用原句、清稿/标注稿、页码和真实修订相符；
改变相关正文后复查受影响引用。只有实际运行上游脚本才报告对应检查结果。
编译可用时检查实际回复 PDF；能力缺失时完成可行工作并准确报告未完成部分。
交付真实修改与回复，不声称整套上游返修流程已执行，不额外启动审稿循环。
```

## Markdown 到 TeX

主 Skill：[09-tex-freeze-formalize](../../.agent/skills/09-tex-freeze-formalize/SKILL.md)。仅在确需切换正文维护源时使用。

```text
依据当前 active_source、目标期刊模板和真实作者决定，完成 Markdown 到 TeX
的正式化。先核对项目现有转换确认；相同转换已有有效批准时继承。
缺批准时先准备可审阅的稳定稿、完整图表/引用与转换范围，再请求对应决定，
不能自行把批准字段改为 true。

保持正文、公式、引文、图表、章节含义和结论边界。只建立一个有效维护源，
按既有事实权威记录源切换，不创建第二套独立正文或冻结凭据。
编译实际 TeX，修复直接错误并检查 PDF 相关页面、交叉引用与资产。
确需且已启用 ARIS 编译能力时，读取 adapter 解析的 paper-compile；Codex 版源：
https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/3e49e63aae6a653067f9e2101d50457f1f7d6a2f/skills/skills-codex/paper-compile/SKILL.md
用现有编译入口和期刊当前官方要求验证，不照搬示例路径、页数、清理命令
或 PDF 体积阈值。上游通用清单不能代替打开实际 PDF。
返回实际源文件与 PDF；编译成功不代表科学结论已验证。
```

## 投稿材料与正式提交

主 Skill：[12-submission-pack](../../.agent/skills/12-submission-pack/SKILL.md)。

```text
根据现用终稿和目标期刊当前官方要求，准备可实际上传的投稿材料。
先核实文章类型、模板、所需文件、作者顺序/贡献、基金与相关声明。
只使用真实信息，缺少作者事实不代填猜测。

按期刊实际要求完成主稿、源文件、图表、补充材料、复现说明、投稿信及
必要 highlights、匿名版本和声明。打开全部交付文件，编译改变的 TeX，
核对稿件、图表、补充材料和投稿信的结论一致性。
正式投稿前更新必要的当前事实，STATUS 仅作为进展视图，不成为第二权威。

先完成可审阅的具体投稿包，再处理作者提交决定。
已有同一版本/范围的明确提交授权时继承；否则请求作者确认正式提交。
使用真实可用的提交渠道，只有系统回执才支持“已投稿”；
未提交、提交失败和缺少渠道/作者输入分别说明。材料清单不是完成的投稿包。
```
