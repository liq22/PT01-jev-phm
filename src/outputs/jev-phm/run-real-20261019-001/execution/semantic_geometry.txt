Calculation:
The stored candidate tensor C was converted to CPU float64 for this diagnostic.
For each class k, norm_k = ||C_k||_2. Cosine[k,j] = (C_k dot C_j)/(norm_k norm_j).
Centered singular values are svdvals(C - mean(C, dim=0, keepdim=True)).
For each saved smoke observation i, logit_range_i = max_k z_ik - min_k z_ik.
The stored smoke output is the source-only post-technical-update output from
three observations, one per class; it is not a held-out diagnostic-performance
estimate. The three saved labels in every smoke output are [0, 1, 2].

H1 interpretation and limits:
The fixed inner/outer prototypes are nearly parallel and the raw dot-product
readout produces substantially larger class-logit ranges on these three saved
smoke observations than the indexed head. This is consistent with an adverse
score-scale/geometry condition under the fixed protocol. It does not identify
geometry as the sole cause of the poor fit: norms/cosines do not by themselves
measure adaptation difficulty or representational adequacy, and a common logit
offset cancels from softmax. No duplicate prototype, nonfinite tensor, candidate
mutation, or label-order mismatch was found in the inspected artifacts/code.
This inspection neither validates the semantic mechanism nor establishes a
universal failure. Trial_00 remains an observed, capped source fit. No new
normalization, temperature, seed, fitting budget or retry was introduced.

CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 .venv/bin/python - <<'PY'
from pathlib import Path
import json
import torch

torch.set_num_threads(1)
run = Path('src/outputs/jev-phm/run-real-20261019-001')
paths = {
    'semantic_smoke': run/'smoke/semantic/model.pt',
    'permuted_smoke': run/'smoke/permuted/model.pt',
    'trial00': run/'fits/semantic/trial_00/model.pt',
}
states = {name: torch.load(path, map_location='cpu', weights_only=True)
          for name, path in paths.items()}
c = states['trial00']['candidates'].double()
norm = torch.linalg.vector_norm(c, dim=1)
cos = (c @ c.T) / (norm[:, None] * norm[None, :])
centered = c - c.mean(0, keepdim=True)
print(json.dumps({
    'candidate_shape': list(c.shape),
    'finite': bool(torch.isfinite(c).all()),
    'norms': norm.tolist(), 'cosines': cos.tolist(),
    'centered_singular_values': torch.linalg.svdvals(centered).tolist(),
    'tau': states['trial00']['tau'], 'readout': states['trial00']['readout'],
    'trial_same_as_smoke': torch.equal(c, states['semantic_smoke']['candidates'].double()),
    'permuted_matches_declared_120': torch.equal(
        states['permuted_smoke']['candidates'],
        states['semantic_smoke']['candidates'][[1, 2, 0]]),
}, indent=2))
for name in ('semantic', 'permuted', 'indexed'):
    out = torch.load(run/f'smoke/{name}/output.pt', map_location='cpu', weights_only=True)
    z, y = out['logits'].double(), out['labels'].long()
    print(json.dumps({'smoke': name, 'labels': y.tolist(), 'logits': z.tolist(),
        'argmax': z.argmax(1).tolist(),
        'class_logit_range': (z.max(1).values-z.min(1).values).tolist()}, indent=2))
for name in ('semantic_smoke', 'trial00'):
    a = states[name]['adapter']
    print(json.dumps({'adapter': name,
        'finite': all(bool(torch.isfinite(t).all()) for t in a.values()),
        'parameter_norms': {k: float(torch.linalg.vector_norm(t.double()))
                            for k, t in a.items()}}, indent=2))
